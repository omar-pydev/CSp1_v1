# Project 1 — Version 1.0

Geolocation detection tool focused on network-based location tracking and data analysis.

---

## Overview
This project is a Python-based geolocation detection system designed to analyze and retrieve location-related information using network and IP data.  
The goal of this project is to improve understanding of networking, geolocation technologies, API integration, and data processing.

This project was created for educational purposes, skill development, and ethical cybersecurity learning.

## Features
- IP-based geolocation detection
- Network information analysis
- Real-time location data retrieval
- Clean and simple Python implementation
- Beginner-friendly project structure
